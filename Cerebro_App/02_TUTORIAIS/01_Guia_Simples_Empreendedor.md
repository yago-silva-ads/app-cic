# Como Usar o Sistema - Guia Simples (Microempreendedor)

Este guia foi feito para ser simples e direto, ideal para qualquer pessoa usar no dia a dia.

## 1. Entrada de Produtos (Leitor Inteligente)
- Acesse a aba **"Entrada Rápida"** (ícone de código de barras).
- **Usando a Câmera:** Aponte o celular para o código de barras.
- **Leitor USB/PC:** Clique no campo de texto e bipe com o leitor físico.
- **Importar Nota (XML):** Clique no botão com ícone de arquivo para puxar os dados da nota fiscal automaticamente.
- O sistema já vai calcular o preço sugerido com base na sua margem de lucro.

## 2. Controle de Estoque
- Acesse a aba **"Estoque"** (ícone de caixa).
- Aqui você vê tudo o que tem na loja.
- Para vender, na mesma aba ou no Caixa, o estoque é atualizado sozinho.

## 3. Relatórios (PDF e Excel)
- Na tela de **Estoque**, procure pelo botão de download (setinha para baixo).
- Escolha **"Exportar PDF"** para salvar um arquivo pronto para impressão.
- Escolha **"Exportar Excel"** para abrir os dados em planilhas (computador).

## 4. Tema Claro e Escuro
- No menu principal (três pontinhos ou menu lateral), você pode alternar entre "Modo Claro" (fundo branco, melhor para o dia) e "Modo Escuro" (fundo preto, descansa a vista).

**Tudo fica em uma única tela**, sem complicações ou necessidade de abrir janelas difíceis.
