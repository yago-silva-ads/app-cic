## 🎯 O Que Mudou?

### ✨ Estatísticas Detalhadas
Agora você pode ver:
- **Faturamento Total**: Quanto você vendeu
- **ROI (Retorno)**: Se o negócio está lucrativo
- **Margem de Lucro**: Quanto você ganha em cada venda
- **Top 5 Produtos**: Quais vendem mais
- **Alerta de Falta**: Produtos com estoque baixo

Abra o Dashboard e procure pela nova aba **"Estatísticas"** ou veja os dados em cards informativos.

Em breve você terá um **painel online** onde pode:

- Acessar de qualquer lugar

## 📈 Principais Métricas Explicadas

| Métrica | O que Significa | Por que Importa |
|---------|-----------------|-----------------|
| **Faturamento** | Total de vendas | Você sabe quanto vende |
| **ROI** | % de lucro sobre o investimento | Identifica se o negócio é viável |
| **Margem de Lucro** | % que fica na sua bolsa | Mostra eficiência de preços |
| **Ticket Médio** | Quanto cada cliente gasta | Indica padrão de compra |
| **Produtos Top** | Mais vendidos e rentáveis | Foco em melhores produtos |
| **Previsão** | Quanto deve vender | Planejamento futuro |

## 💡 Exemplos Práticos

### Exemplo 1: Entender a Margem de Lucro
```
Se você comprou um item por R$ 10 e vendeu por R$ 15:
- Margem = R$ 5 por venda (33%)
- Se vender 100 unidades = R$ 500 de lucro

O app mostra a margem média de TUDO que você vende.
```

### Exemplo 2: Identificar Produtos em Falta
```
O app alerta quando um produto cai para menos de 5 unidades:
⚠️ "Produto A: apenas 3 unidades"

Você sabe na hora que precisa repor!
```

### Exemplo 3: Tomar Decisões com Dados
```
Se o ROI está em 25%, você sabe que:
- A cada R$ 100 investido, você ganha R$ 25
- Isso é bom? Melhor que deixar na poupança!
```

## 🚀 Como Usar

### 1. Ver Estatísticas (No App)

**Android/iOS:**
```
1. Abra o App
2. Toque em "Dashboard & IA"
3. Veja a aba "Estatísticas"
4. Puxe para baixo para atualizar
```

**Web:**
```
1. Acesse o app no navegador
2. Mesmos passos acima
```

### 2. Monitorar Vendas

A cada venda registrada, os dados são atualizados **em tempo real**:
- Faturamento sobe
- ROI recalcula
- Previsão ajusta

### 3. Receber Alertas

Se algo não está bem, você vê alertas:
- 📉 "Margem caiu para 15%"
- 📦 "Produto em falta!"
- 📊 "Meta diária não atingida"

## ❓ Dúvidas Comuns

### P: Os dados são atualizados em tempo real?
R: Sim! Cada venda que você registra atualiza os gráficos em segundos.

### P: Posso compartilhar com meu sócio?
R: Sim! O desenvolvedor pode gerar um link para compartilhar.

### P: E se eu errar um preço? Afeta o ROI?
R: Sim. É importante colocar o preço correto. Se errar, edite no Estoque Atual.

### P: Posso exportar um relatório?
R: Em breve sim! Por enquanto, tire print dos gráficos.

### P: Como sei se meu negócio vai bem?
R: Compare seu ROI com a meta. Se está acima de 20%, está ótimo!

### P: O que fazer se a margem cair?
R: Pode ser que tenha comprado mais caro ou vendido mais barato. Revise seus preços.
